# Machine Learning Architecture & Pipelines

The platform incorporates dedicated regression pipelines for solar and wind resource estimation, trained using physics-informed synthetic datasets grounded in real meteorological relationships.

---

## 1. Solar Potential ML Pipeline

### Target Variable
- **Capacity Factor (%)**: The ratio of actual energy output over a year to maximum rated output.
- **Expected MWh / Year**: Annual energy generated by a standard 50 MW bifacial PV plant.

### Input Features
1. `latitude` (°N)
2. `longitude` (°W)
3. `elevation_m` (meters above sea level)
4. `slope_deg` (terrain incline)
5. `cloud_cover_pct` (mean annual cloud cover percentage)
6. `temperature_c` (mean ambient temperature)
7. `rainfall_mm` (annual precipitation)
8. `ndvi` (Normalized Difference Vegetation Index)
9. `ghi_kwh_m2_day` (Global Horizontal Irradiance)

### Algorithms & Performance
- **Primary**: Gradient Boosting Regressor / XGBoost
- **Alternative**: Random Forest Regressor
- **Validation Metrics**:
  - $R^2 \ge 0.93$
  - $\text{RMSE} \le 0.85$
  - $\text{MAE} \le 0.62$

---

## 2. Wind Potential ML Pipeline

### Target Variable
- **Capacity Factor (%)**: Evaluated on an IEC Class II 100m hub-height turbine power curve.
- **Wind Power Density ($W/m^2$)**: $0.5 \times \rho \times v^3$, where $\rho$ is air density dynamically calculated from barometric elevation pressure.

### Input Features
1. `latitude` (°N)
2. `longitude` (°W)
3. `elevation_m` (meters)
4. `slope_deg` (terrain ruggedness)
5. `temperature_c` (air temperature)
6. `wind_speed_100m` (mean wind speed at 100m hub height)

### Algorithms & Performance
- **Primary**: Gradient Boosting Regressor / LightGBM
- **Alternative**: Random Forest Regressor
- **Validation Metrics**:
  - $R^2 \ge 0.91$
  - $\text{RMSE} \le 1.15$
  - $\text{MAE} \le 0.84$

---

## 3. Model Persistence & Retraining

Models are serialized into self-contained joblib bundles located at:
`backend/app/ml/artifacts/solar_model.joblib`
`backend/app/ml/artifacts/wind_model.joblib`

Models can be retrained on-demand via the API (`POST /api/v1/solar/train`, `POST /api/v1/wind/train`) or via the command line:
```bash
python scripts/train_models.py
```
